# 🌐 Flask Blog Website

Welcome to my Flask Blog Website! This is a simple blogging website that I built while learning **Python Flask** and web development. It demonstrates how Flask works with HTML, CSS, Jinja templates, and forms.

## 📖 About the Project

This project is a basic blog website created using Flask. It contains multiple pages such as Home and About, and also includes a Contact Form where users can submit their details. The project helped me understand Flask routing, template inheritance, and handling GET and POST requests.

## ✨ Features

* Home page with blog content.
* About page.
* Contact form for user details.
* Flask GET and POST request handling.
* Reusable templates using `base.html`.
* Static CSS for styling.

## 🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* Jinja2
* Git & GitHub
